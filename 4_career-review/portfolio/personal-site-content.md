## 16. Build notes (it's a static single-pager, keep it light)
- Vanilla HTML/CSS/JS is plenty — you don't need a framework for one fun page (and it'll load instantly, which is *itself* on-brand for a reliability person).
- Pick **one** big bit (the character sheet OR the typewriter hero OR the cursor cat) as the centerpiece; let the rest be small touches. Over-stuffing kills the charm.
- Keep the load-bearing facts true (8 yrs, 45k, zero failures ×5, founding→Director); let the obvious jokes be obviously jokes. Recruiters *will* visit this from your LinkedIn — fun is great, but the real signal should still land for a skim-reader.
- Mobile: the RPG/stat blocks should stack gracefully. Cat-follows-cursor → disable on touch.
- One tasteful animation > ten. Respect `prefers-reduced-motion`.
